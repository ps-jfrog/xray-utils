# Templates

Templates are grouped by **command**. Each subdirectory matches a plugin command and contains sample inputs or request bodies for that command.

| Directory | Command | Description |
|-----------|---------|-------------|
| [create-ignore-rule/](create-ignore-rule/) | `create-ignore-rule` | JSON request bodies for the Xray Create Ignore Rule API. |
| [set-license-priority/](set-license-priority/) | `set-license-priority` | No file templates; the command takes `license-name` and `license-priority` as arguments. |
